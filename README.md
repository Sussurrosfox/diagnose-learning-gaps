# Diagnose Learning Gaps (学困生知识摸底器)

> 一个用于智能体（AI Agent）的专业诊断技能：从学生最初提问或不会做的题目出发，构建最小前置知识图，通过带“不知道”选项的自适应单题选择题下钻定位知识断层，最终输出结构化诊断报告与精准补学建议。

---

## 🎯 核心目标

当学生面对题目无从下手或反复出错时，往往不是当前题目的技巧问题，而是**前置知识链条发生了断层**。
本技能旨在：
1. **建立最小前置知识图**：反向递归拆解解出原题所必需的最少概念、规则与综合能力。
2. **自适应下钻定位**：通过逐题动态互动，精准找到“已掌握边界之后的第一个缺失节点”。
3. **输出专业学情报告**：明确学生已知基础、缺失知识链条、关键阻断缺口及循序渐进的补学顺序。

---

## ⚡ 核心原则与设计机制

1. **一次只出一道题**：出题后即刻暂停等待作答，避免认知过载。
2. **强制提供「不知道」选项**：默认 A/B/C 为内容选项，D 为「不知道」且永不对正确答案设在 D，让学生无心理负担地自报盲区，消除盲目乱猜。
3. **单题单点纯净检测**：每题只测一个原子知识点，排除多重混杂干扰。
4. **动态自适应选题**：
   - 答错或选「不知道」 $\rightarrow$ 下钻直接前置节点，定位基础边界；
   - 答对 $\rightarrow$ 换情境复核稳定性，并转向其它必要分支；
   - 前置皆会但综合题不会 $\rightarrow$ 定位多步连接与整合能力缺失。
5. **诊断优先，不急于讲题**：诊断过程中保持客观记录，不剧透答案、不展开授课，避免破坏诊断的自洽性。
6. **教育同理心与保护自尊**：内部标签与外部报告均使用“尚未掌握”“掌握不稳”，坚决不使用“笨”“基础差”等负面标签。

---

## 📋 诊断报告结构

诊断结束（通常 8~15 题收敛）后，将自动输出标准化诊断报告：

1. **诊断概况**：初始题目概括、检测覆盖分支与总体结论。
2. **已知知识基础**：明确列出学生已稳定掌握的先验知识与答题证据。
3. **缺失知识链条**：可视化展示 `[已掌握] 节点 A → [掌握不稳] 节点 B → [已确认缺失] 节点 C → [目标]`。
4. **关键缺口解释**：阐释最早发生断层的原子节点如何阻断了后续解题。
5. **建议补学顺序**：按前置依赖关系规划 3~5 个节点的补学路径。
6. **诊断局限**：客观说明未检测范围、样本量与置信度边界。

## 🚀 安装与使用

将本项目克隆或放置到你的 AI Agent 工具/技能目录下即可生效：

### 在 Antigravity 中使用
将目录复制到技能配置目录：
```bash
git clone https://github.com/Sussurrosfox/diagnose-learning-gaps.git ~/.gemini/config/skills/diagnose-learning-gaps
```

### 在 Kimi Code CLI / Claude Code 中使用
放置在对应的技能搜索路径下（例如 `~/.config/agents/skills/diagnose-learning-gaps`），Agent 在遇到学情诊断、错因分析、知识摸底等场景时将自动触发本技能。
